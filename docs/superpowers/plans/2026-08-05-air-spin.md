# Air Spin Rotation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** While airborne (including transfer), hold rotate left/right to yaw; land near *N×180°* or fall; never change `velocity.x` from spin; backwards land flips facing to momentum without board re-yaw.

**Architecture:** `PlayerSim` / `AirSolver` own continuous `spin_yaw` on physics ticks. Presentation composes it onto body/board yaw. Land classify uses a debug-tunable window; success snaps to exact *N×π* then optionally momentum-corrects discrete facing only.

**Tech Stack:** Godot 4.7 GDScript analytical sim (`scripts/sim/`), existing `LogicalPose` / `BoardYawTracker`, headless `tests/sim/test_sim_runtime.gd`.

**Approved design:** [`docs/superpowers/specs/2026-08-05-air-spin-design.md`](../specs/2026-08-05-air-spin-design.md).

## Global Constraints

- Simulation on physics ticks only; presentation never classifies land or writes facing/vx
- Spin must not modify `velocity.x` / planar X speed
- Aerial vocabulary unchanged (air-out / fly-out / transfer); spin is an additive air control
- Motion vectors stay `INPUT` / `MOMENTUM` / `ACTUAL` — do not invent spin-velocity aliases
- Fall uses existing `begin_fall()` path

## Yaw composition (locked)

- **Discrete** `SimState.facing` (`l`/`r`): flips live when `spin_yaw` crosses odd *N×π* from bout zero; momentum fix may flip again on successful land without touching board
- **Continuous** `spin_yaw`: integrated while held airborne; freeze on release or land
- **Hang apex** keeps using existing `facing_yaw` lerp; display body yaw = `facing_yaw + spin_yaw` (+ depth-turn in pose)
- **Board:** `BoardYawTracker` advances by `delta(spin_yaw)` each tick (and existing apex `facing_yaw` deltas). Momentum facing fix must **not** call `snap_to_facing`
- **Bout zero:** `spin_yaw = 0` on `_enter_air` / new air bout; **do not** reset mid-transfer

## Defaults

- `SPIN_RATE` ≈ `PI` rad/s (debug slider)
- `LAND_SPIN_WINDOW` ≈ `25°` half-width (debug slider)
- Both held → rate 0
